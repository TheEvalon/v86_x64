Windows XP Professional x64 Edition

Local tester for a gitignored IDE disk. Matches QEMU pc-i440fx + 512 MB + ACPI (do not switch the guest to Standard PC).
Looking for a local disk…
Serve this repo over HTTP with a server that supports Range (XAMPP/Apache does; python -m http.server does not), not file://. After clone, run make so build/v86-debug.wasm exists. Unzip your disk and put the raw image at images/windows-xp-x64.img (also accepts images/hdd.img, xp64.img, winxp64.img), or pick the .img here (the file picker does not need Range). A .zip works only if the disk inside is stored uncompressed; otherwise unzip first. Override the URL with ?hda=images/hdd.img. The disk is not part of git (images/ and *.img are ignored).
