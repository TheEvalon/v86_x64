Looking for a local disk or CD…
Serve this repo over HTTP with a server that supports Range (XAMPP/Apache does; python -m http.server does not), not file://. After clone, run make all so build/v86.wasm exists (faster than make's debug wasm). This page prefers the release build; add ?debug=1 to force v86-debug.wasm. Unzip your disk and put the raw image at images/windows-xp-x64.img (also accepts images/hdd.img, xp64.img, winxp64.img), or pick the .img here (the file picker does not need Range). A .iso goes in the CD-ROM picker (or images/windows-xp-x64.iso / ?cdrom=images/foo.iso). The VM does not start until you click Start; picking a disk or CD only selects media and boot order (hard disk first vs CD-ROM first). A .zip works only if the disk inside is stored uncompressed; otherwise unzip first. Override the disk URL with ?hda=images/hdd.img. ?autostart=1 starts as soon as a disk or CD is found. ?boot_order=123 (CD first) or 312 (HDD first). ?sync_jit=1 (or the 64-bit JIT box) compiles 64-bit CS, including the high-RIP ALU/REX/LEA whitelist. INT3 padding is not compiled. Leave it off for XP until a timed boot: Jcc/0F at kernel RIP still interpret. A broader compiler used to hit STOP 0x7E. Disk Range reads are coalesced to 256 KiB (same as copy.sh Windows images). Without that, XP issues 10–100 KB ATA reads as separate HTTP requests and boot stretches into tens of minutes even on a fast SSD. Override with ?chunk_size=1048576 on localhost. After long mode, 64-bit CS is interpreted (faster than trampoline JIT). First desktop is still several minutes in the browser; then Save state. The disk is not part of git (images/ and *.img are ignored). After the first desktop, Save state downloads xp64-state.bin (shown in the status line). Put that file at images/xp64-state.bin (gitignored) and reopen xp.html?state=images/xp64-state.bin (or .zst; v86 decompresses state images). Restore needs the same RAM, ACPI, and disk as when you saved. A copy can stay in this browser via IndexedDB (Restore last local state after a refresh). Save / Restore keeps one snapshot in memory for this tab.
