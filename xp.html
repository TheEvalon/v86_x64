Serve this repo over HTTP with a server that supports Range (XAMPP/Apache does; python -m http.server does not), not file://. After clone, run make all so build/v86.wasm exists (faster than make's debug wasm). This page prefers the release build; add ?debug=1 to force v86-debug.wasm. Unzip your disk and put the raw image at images/windows-xp-x64.img (also accepts images/hdd.img, xp64.img, winxp64.img), or pick the .img here (the file picker does not need Range). A .zip works only if the disk inside is stored uncompressed; otherwise unzip first. Override the URL with ?hda=images/hdd.img. Disk Range reads are coalesced to 256 KiB (same as copy.sh Windows images). Without that, XP issues 10–100 KB ATA reads as separate HTTP requests and boot stretches into tens of minutes even on a fast SSD. Override with ?chunk_size=1048576 on localhost. The disk is not part of git (images/ and *.img are ignored). After the first desktop, Save state downloads xp64-state.bin (shown in the status line). Put that file at images/xp64-state.bin (gitignored) and reopen xp.html?state=images/xp64-state.bin (or .zst; v86 decompresses state images). Restore needs the same RAM, ACPI, and disk as when you saved. A copy can stay in this browser via IndexedDB (Restore last local state after a refresh). Save / Restore keeps one snapshot in memory for this tab.
